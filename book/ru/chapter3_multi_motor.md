## Чему ты научишься

Время повышать уровень! Ты собираешься управлять **4 моторами одновременно**, чтобы сделать настоящего робота, который может двигаться.

В этой главе ты:

- Создашь крутые паттерны движения
- Поймёшь, как роботы движутся

## Как роботы движутся

### Один мотор против нескольких моторов

**Один мотор:** Может только вращаться на месте
- Хорошо для: Вентиляторов, вращающихся вещей, одной движущейся части

**Несколько моторов:** Могут заставлять вещи двигаться!
- 2 мотора: Могут ехать вперёд/назад и поворачивать (как танк)
- 4 мотора: Могут двигаться в ЛЮБОМ направлении (вперёд, вбок, по диагонали, вращаясь)

### Знакомься с моторами своего робота

У твоего робота 4 мотора, по одному на каждое колесо:

```
       ПЕРЁД
   FL      FR
   (4)     (2)

   BL      BR
   (3)     (1)
       ЗАД
```

У каждого мотора есть номер:
- **FL (Переднее-Левое)** = Мотор 4
- **FR (Переднее-Правое)** = Мотор 2
- **BL (Заднее-Левое)** = Мотор 3
- **BR (Заднее-Правое)** = Мотор 1

**Запомни:** Эти номера остаются одинаковыми для всех наших программ!

## Урок 2.1: Два мотора вместе

**Цель:** Заставь два мотора вращаться одновременно!

### Код

```python
from evabot import Motor
import time

# Создай два мотора
motor1 = Motor(1)  # Заднее-правое колесо
motor2 = Motor(2)  # Переднее-правое колесо

# Разбуди оба
motor1.start()
motor2.start()

# Заставь оба ехать вперёд
motor1.run(30)
motor2.run(30)
time.sleep(3)

# Останови оба
motor1.stop()
motor2.stop()
```

```bash

```

Оба мотора должны вращаться вместе!

### Заставь их делать разные вещи

**Одно направление (робот едет прямо):**
```python
motor1.run(30)   # Правая сторона вперёд
motor2.run(30)   # Правая сторона вперёд
# Робот движется вперёд!
```

**Противоположные направления (робот поворачивает):**
```python
motor1.run(30)    # Один мотор вперёд
motor2.run(-30)   # Другой мотор назад
# Робот вращается по кругу!
```

**Разные скорости (робот изгибается):**
```python
motor1.run(60)   # Правый мотор быстрее
motor2.run(20)   # Правый мотор медленнее
# Робот изгибается!
```

### Важно: Отправляй команды вместе!

**Правильный способ (моторы движутся вместе):**
```python
motor1.run(30)    # Скажи мотору 1 ехать
motor2.run(30)    # Скажи мотору 2 ехать
time.sleep(3)     # Теперь жди
```

**Неправильный способ (моторы не движутся вместе):**
```python
motor1.run(30)
time.sleep(3)      # Мотор 1 движется один
motor2.run(30)     # Мотор 2 ещё не начал!
time.sleep(3)
```

Всегда говори ВСЕМ моторам, что делать, ЗАТЕМ жди!

### Использование списка

Вместо того чтобы писать `motor1`, `motor2` снова и снова, используй список:

```python
# Создай моторы в списке
motors = [Motor(1), Motor(2)]

# Запусти все моторы
for motor in motors:
    motor.start()

# Запусти все моторы
for motor in motors:
    motor.run(30)

time.sleep(3)

# Останови все моторы
for motor in motors:
    motor.stop()
```

Это супер полезно, когда у тебя много моторов!

## Урок 2.2: Четыре мотора (Твой робот!)

**Цель:** Управляй всеми 4 колёсами, чтобы заставить робота двигаться!

### Создание всех четырёх моторов

```python
from evabot import Motor

# Создай все 4 мотора
fl = Motor(4)  # Переднее-левое
fr = Motor(2)  # Переднее-правое
bl = Motor(3)  # Заднее-левое
br = Motor(1)  # Заднее-правое

# Разбуди всех
fl.start()
fr.start()
bl.start()
br.start()

# Или используй цикл!
motors = [fl, fr, bl, br]
for motor in motors:
    motor.start()
```

### Заставь робота ехать вперёд

Чтобы ехать вперёд, ВСЕ колёса вращаются в одном направлении:

```python
fl.run(40)
fr.run(40)
bl.run(40)
br.run(40)
time.sleep(3)  # Едь вперёд 3 секунды
```

Твой робот должен катиться вперёд!

### Заставь робота вращаться

Чтобы вращаться на месте, левые колёса едут в одну сторону, правые колёса в другую:

```python
# Левые колёса вперёд, правые колёса назад = Вращение вправо
fl.run(40)
bl.run(40)
fr.run(-40)
br.run(-40)
time.sleep(2)  # Вращайся 2 секунды
```

Твой робот должен вращаться по кругу!

### Магия меканум-колёс

У твоего робота есть специальные колёса, называемые "меканум-колёса". Они могут двигаться вбок!

**Диагональное движение:**
```python
# Противоположные углы в одном направлении
fl.run(40)
br.run(40)
fr.run(-40)
bl.run(-40)
time.sleep(2)
```

Твой робот движется по диагонали! Это как магия - обычные колёса так не могут!

### Полный пример движения

```python
from evabot import Motor
import time

# Создай все моторы
fl, fr, bl, br = Motor(4), Motor(2), Motor(3), Motor(1)

# Запусти все
for m in [fl, fr, bl, br]:
    m.start()

print("Едем вперёд...")
for m in [fl, fr, bl, br]:
    m.run(40)
time.sleep(2)
for m in [fl, fr, bl, br]:
    m.hold()

time.sleep(0.5)

print("Вращаемся вправо...")
fl.run(40)
bl.run(40)
fr.run(-40)
br.run(-40)
time.sleep(2)
for m in [fl, fr, bl, br]:
    m.hold()

time.sleep(0.5)

print("Едем по диагонали...")
fl.run(40)
br.run(40)
fr.run(-40)
bl.run(-40)
time.sleep(2)

# Останови всё
for m in [fl, fr, bl, br]:
    m.stop()

print("Готово!")
```

### Проверка каждого мотора

Хочешь убедиться, что все моторы работают? Протестируй их по одному:

```python
motors = {
    'FL': Motor(4),
    'FR': Motor(2),
    'BL': Motor(3),
    'BR': Motor(1)
}

for motor in motors.values():
    motor.start()

# Протестируй каждый мотор
for name, motor in motors.items():
    print(f"\nТестирую {name}...")
    motor.run(40)
    time.sleep(1)
    motor.hold()
    print(f"{name} позиция: {motor.get_position()}")
    time.sleep(0.5)

for motor in motors.values():
    motor.stop()
```

Все моторы должны двигаться! Если один не двигается, проверь его соединения.

## Урок 2.3: Паттерны движения

**Цель:** Создай крутые паттерны, комбинируя движения моторов!

### Паттерн 1: Езда вперёд

```python
def drive_forward(motors, speed, duration):
    """Все моторы в одном направлении"""
    for motor in motors:
        motor.run(speed)
    time.sleep(duration)
    for motor in motors:
        motor.hold()

# Используй это
motors = [Motor(i) for i in [1, 2, 3, 4]]
for m in motors:
    m.start()

drive_forward(motors, 40, 3)  # Вперёд 3 секунды

for m in motors:
    m.stop()
```

### Паттерн 2: Вращение по кругу

```python
def spin_right(fl, fr, bl, br, speed, duration):
    """Вращение по часовой стрелке"""
    # Левая сторона вперёд
    fl.run(speed)
    bl.run(speed)
    # Правая сторона назад
    fr.run(-speed)
    br.run(-speed)

    time.sleep(duration)

    # Останови всё
    for m in [fl, fr, bl, br]:
        m.hold()

# Используй это
fl, fr, bl, br = Motor(4), Motor(2), Motor(3), Motor(1)
for m in [fl, fr, bl, br]:
    m.start()

spin_right(fl, fr, bl, br, 40, 2)

for m in [fl, fr, bl, br]:
    m.stop()
```

### Паттерн 3: Движение по диагонали

```python
def move_diagonal(fl, fr, bl, br, speed, duration):
    """Диагональное движение (магия меканум!)"""
    # Противоположные углы вместе
    fl.run(speed)
    br.run(speed)
    fr.run(-speed)
    bl.run(-speed)

    time.sleep(duration)

    for m in [fl, fr, bl, br]:
        m.hold()
```

### Паттерн 4: Танцевальное движение!

Комбинируй движения, чтобы заставить робота танцевать:

```python
fl, fr, bl, br = Motor(4), Motor(2), Motor(3), Motor(1)
for m in [fl, fr, bl, br]:
    m.start()

print("Робот начинает танцевать!")

# Вперёд
print("Шаг 1: Вперёд!")
for m in [fl, fr, bl, br]:
    m.run(40)
time.sleep(1)
for m in [fl, fr, bl, br]:
    m.hold()

# Вращение влево
print("Шаг 2: Вращение влево!")
fl.run(-40)
bl.run(-40)
fr.run(40)
br.run(40)
time.sleep(1)
for m in [fl, fr, bl, br]:
    m.hold()

# Диагонально вправо
print("Шаг 3: По диагонали!")
fl.run(40)
br.run(40)
fr.run(-40)
bl.run(-40)
time.sleep(1)
for m in [fl, fr, bl, br]:
    m.hold()

# Вращение вправо
print("Шаг 4: Вращение вправо!")
fl.run(40)
bl.run(40)
fr.run(-40)
br.run(-40)
time.sleep(1)

print("Танец завершён!")
for m in [fl, fr, bl, br]:
    m.stop()
```

## Понимание движения робота

### Как 4 колеса создают разные движения?

**Все в одном направлении = Вперёд/Назад**
```
FL → → FR
BL → → BR
Результат: Робот едет вперёд →
```

**Левые вперёд, Правые назад = Вращение вправо**
```
FL → → FR
       ← ←
BL → → BR
       ← ←
Результат: Робот вращается ↻
```

**Диагонально (Магия меканум!)**
```
FL → →  ← ← FR
       ↘
BL ← ←  → → BR
Результат: Робот движется по диагонали ↘
```

Специальные меканум-колёса позволяют тебе двигаться вбок - обычные колёса так не могут!

### Почему моторам иногда нужны разные скорости?

Моторы не идеальны - они могут вращаться с немного разными скоростями, даже когда ты говоришь им одинаковое число. Это нормально!

Ты можешь проверить, считав их позиции:

```python
fl.run(40)
fr.run(40)
bl.run(40)
br.run(40)
time.sleep(2)

print(f"FL переместился: {fl.get_position()} импульсов")
print(f"FR переместился: {fr.get_position()} импульсов")
print(f"BL переместился: {bl.get_position()} импульсов")
print(f"BR переместился: {br.get_position()} импульсов")
```

Числа должны быть близкими (в пределах 100-200 импульсов). Позже ты научишься делать их ещё более точными!

## Важные советы для нескольких моторов

### Совет 1: Всегда запускай все моторы сначала

```python
# Хорошо!
motors = [Motor(1), Motor(2), Motor(3), Motor(4)]
for m in motors:
    m.start()  # Сначала запусти все

# Теперь используй их
for m in motors:
    m.run(40)
```

### Совет 2: Отправляй команды всем моторам, затем жди

```python
# Хорошо! (моторы движутся вместе)
motor1.run(40)
motor2.run(40)
motor3.run(40)
motor4.run(40)
time.sleep(3)  # Жди после командования всем

# Плохо! (моторы движутся по одному)
motor1.run(40)
time.sleep(3)  # Мотор 1 движется один
motor2.run(40)
time.sleep(3)  # Мотор 2 ещё не начал
```

### Совет 3: Всегда останавливай все моторы в конце

```python
# Используй цикл, чтобы остановить все моторы
for motor in motors:
    motor.stop()
```

Или даже лучше, используй `try/finally`, чтобы убедиться, что моторы ВСЕГДА останавливаются:

```python
motors = [Motor(i) for i in [1, 2, 3, 4]]
try:
    # Запусти моторы
    for m in motors:
        m.start()

    # Твой код робота здесь
    for m in motors:
        m.run(40)
    time.sleep(3)

finally:
    # Это ВСЕГДА выполняется, даже если есть ошибка
    for m in motors:
        m.stop()
```
