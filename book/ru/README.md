# Учебник по EvaBot

**От нуля до автономного робота**

Добро пожаловать в учебник по EvaBot! Эта книга научит тебя программированию роботов шаг за шагом, начиная с управления одним мотором и заканчивая созданием автономных роботов с сенсорами и поведением.

## Чему ты научишься

Этот учебник использует постепенный подход к робототехнике:

1. **Управление моторами** - Начни с одного мотора, изучи основы
2. **Многомоторные системы** - Координируй несколько моторов вместе
3. **Системы движения** - Построй меканум-привод для движения во всех направлениях
4. **Сенсоры** - Добавь лидар и камеры для восприятия
5. **Автономное поведение** - Создай роботов, которые думают и действуют самостоятельно
6. **Навигация** - SLAM, картографирование и планирование пути

## Как работает эта книга

Каждая глава основывается на предыдущих:

- **Секции теории** - Краткие объяснения концепций (системы координат, кинематика и т.д.)
- **Практические уроки** - Упражнения по программированию с реальным оборудованием
- **Примеры кода** - Рабочие решения, которые можно запустить сразу
- **Справочное руководство** - Полная документация API для всех функций

Новичок в программировании? Начни здесь!

Изучи ровно столько Python, сколько нужно для робототехники:

- Условия if (принятие решений)
- Циклы (повторение действий)
- Функции (переиспользование кода)

### ✅ Глава 1: Начало работы
**Статус:** Готово

Изучи основы:
- Установка EvaBot и подключение к роботу
- Твоя первая программа для мотора
- Понимание команд `robot`
- Функции безопасности и решение проблем

**Время:** 30-45 минут

---

### ✅ Глава 2: Управление моторами
**Статус:** Готово

Освой управление одним мотором:
- **Урок 1.1:** Заставь его крутиться
- **Урок 1.2:** Управление скоростью (вперёд, назад, изменение скорости)
- **Урок 1.3:** Старт и стоп (hold, disable, stop)
- **Урок 1.4:** Чтение позиции (обратная связь энкодера)
- **Урок 1.5:** Движение на точное расстояние (управление позицией)

**Время:** 2-3 часа

---

### ✅ Глава 3: Несколько моторов
**Статус:** Готово

Управляй несколькими моторами одновременно:
- **Урок 2.1:** Два мотора работают вместе
- **Урок 2.2:** Четыре мотора (полноценный робот!)
- **Урок 2.3:** Паттерны движения (вперёд, вращение, по диагонали)

Узнай магию меканум-колёс и координацию робота!

**Время:** 2-3 часа

---

### 📋 Глава 4: Системы движения
**Статус:** Скоро будет

Построй настоящую систему движения:
- Кинематика меканум (как работает движение во всех направлениях)
- Высокоуровневое управление (движение в метрах/секунду вместо RPM)
- Одометрия (робот знает, где он находится!)
- Паттерны движения и траектории
- **Уроки**: 3.1 - 3.6

---

### 📋 Глава 5: Сенсоры
**Статус:** Запланировано

Добавь глаза и уши своему роботу:
- RPLidar для обнаружения препятствий
- Камера Orbbec для зрения
- Обработка данных сенсоров
- Объединение данных сенсоров

---

### 📋 Глава 6: Автономное поведение
**Статус:** Запланировано

Научи роботов думать:
- Конечные автоматы
- Реактивное поведение
- Планирование на основе целей
- Принятие решений

---

### 📋 Глава 7: Навигация и SLAM
**Статус:** Запланировано

Продвинутая навигация:
- Картографирование с помощью лидара
- Локализация (знать, где ты находишься)
- Планирование пути
- Автономная навигация
