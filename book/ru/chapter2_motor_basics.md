## Урок 1.1: Заставь его крутиться

**Цель:** Заставь свой первый мотор вращаться!

### Код

```bash
robot lesson 1.1
cd lesson1_1
robot run solution.py
```

Смотри на мотор! Он должен вращаться 3 секунды, а потом остановиться.

### Что происходит?

```python
from evabot import Motor
import time

motor = Motor(1)     # Подключись к мотору №1
motor.start()        # Разбуди его
motor.run(30)        # Вращайся со скоростью 30 RPM
time.sleep(3)        # Жди 3 секунды
motor.stop()         # Останови и разблокируй
```

Представь мотор как игрушку с выключателем:
- `motor.start()` = Включи его
- `motor.run(30)` = Заставь работать со скоростью 30
- `motor.stop()` = Выключи его

### Попробуй это!

**Заставь его вращаться быстрее:**
```python
motor.run(60)   # В два раза быстрее!
```

**Заставь его вращаться дольше:**
```python
time.sleep(10)  # Вращайся 10 секунд вместо 3!
```

## Урок 1.2: Управление скоростью

**Цель:** Изменяй скорость мотора во время работы!

### Изменение скорости в действии

```python
motor.start()

print("Начинаем медленно...")
motor.run(20)      # Медленно
time.sleep(2)

print("Ускоряемся!")
motor.run(60)      # Быстрее
time.sleep(2)

print("Замедляемся...")
motor.run(30)      # Средне
time.sleep(2)

print("Едем назад!")
motor.run(-40)     # Реверс!
time.sleep(2)

motor.stop()
```

**Запусти:**
```bash
robot lesson 1.2
cd lesson1_2
robot run solution.py
```

Ты должен услышать, как мотор ускоряется и замедляется!

### Понимание скорости

**RPM означает "Оборотов в минуту":**
- `motor.run(30)` = 30 оборотов за одну минуту (пол-оборота в секунду)
- `motor.run(60)` = 60 оборотов за одну минуту (1 оборот в секунду)
- `motor.run(120)` = 120 оборотов за одну минуту (2 оборота в секунду)

**Направление:**
- Положительное число = Вперёд (по часовой стрелке)
- Отрицательное число = Назад (против часовой стрелки)
- Ноль = Стоп

```python
motor.run(50)    # Вперёд на 50 RPM
motor.run(-50)   # Назад на 50 RPM
motor.run(0)     # Стоп
```

### Задача: Разгон скорости

motor.start()

for speed in range(10, 101, 10):  # 10, 20, 30, ... 100
    print(f"Скорость: {speed} RPM")
    motor.run(speed)
    time.sleep(1)

## Урок 1.3: Старт и стоп

**Цель:** Узнай разные способы остановки мотора.

### Три способа остановить

**1. `hold()` - Останови, но оставайся заблокированным**

```python
motor.run(30)
time.sleep(2)
motor.hold()      # Прекрати движение, но вал остаётся заблокированным
```

Мотор перестаёт вращаться, но ты всё ещё не можешь повернуть его рукой. Это как нажать "паузу" на видео.

**Когда использовать:** Когда хочешь временно остановиться, но держать мотор готовым.

**2. `disable()` - Разблокируй вал**

```python
motor.run(30)
time.sleep(2)
motor.disable()   # Останови и разблокируй вал
```

Мотор останавливается, И теперь ты можешь повернуть его рукой. Это как усыпить мотор.

**Когда использовать:** Когда закончил работу и хочешь сэкономить энергию или отрегулировать позицию мотора вручную.

**3. `stop()` - Полная остановка**

```python
motor.run(30)
time.sleep(2)
motor.stop()      # Останови, разблокируй и очисти
```

Это делает всё: останавливает мотор, разблокирует его и очищает. Используй это в конце программы.

### Попробуй сам

```bash
robot lesson 1.3
cd lesson1_3
robot run solution.py
```

Программа продемонстрирует все три способа остановки!

### Когда какой использовать?

Представь это так:

```
hold() = Кнопка паузы
├─ Мотор перестаёт двигаться
├─ Вал остаётся заблокированным
└─ Готов снова двигаться быстро

disable() = Режим сна
├─ Мотор перестаёт двигаться
├─ Вал разблокируется (можешь повернуть его)
└─ Экономит энергию

stop() = Выключить
├─ Мотор перестаёт двигаться
├─ Вал разблокируется
└─ Полная очистка (используй в конце программы)
```

## Урок 1.4: Чтение позиции

**Цель:** Научись видеть, как далеко повернулся твой мотор!

### Встроенный счётчик мотора

У каждого мотора есть встроенный счётчик (называется энкодер), который считает, сколько раз он вращается. Он супер точный - может считать **3200 шагов за оборот**!

### Чтение позиции

```python
motor.start()

# Посмотри, где мы начали
start_position = motor.get_position()
print(f"Начинаем с: {start_position}")

# Вращайся 2 секунды
motor.run(60)  # 60 RPM = 1 оборот в секунду
time.sleep(2)

# Посмотри, где мы закончили
end_position = motor.get_position()
print(f"Заканчиваем на: {end_position}")

# Посчитай, как далеко мы переместились
distance = end_position - start_position
print(f"Переместились на {distance} шагов")
print(f"Это примерно {distance / 3200} оборотов")

motor.stop()
```

### Понимание чисел

Позиция измеряется в "импульсах" (также называются шаги):
- **3200 импульсов** = 1 полный оборот (360 градусов)
- **1600 импульсов** = половина оборота (180 градусов)
- **800 импульсов** = четверть оборота (90 градусов)

**Чтобы конвертировать импульсы в обороты:**
```python
rotations = pulses / 3200
```

**Чтобы конвертировать импульсы в градусы:**
```python
degrees = pulses / 8.889  # Потому что 3200 ÷ 360 = 8.889
```

### Смотри, как считает!

Эта программа показывает позицию, пока мотор работает:

```python
motor.start()
motor.run(60)  # 1 оборот в секунду

# Покажи позицию 10 раз
for i in range(10):
    pos = motor.get_position()
    rotations = pos / 3200
    print(f"Позиция: {pos:6d} импульсов = {rotations:.2f} оборотов")
    time.sleep(0.5)

motor.stop()
```

**Попробуй:**
```bash
robot lesson 1.4
cd lesson1_4
robot run solution.py
```

Ты увидишь, как число растёт, пока мотор вращается!

### Проверь скорость своего мотора

Действительно ли твой мотор вращается с той скоростью, которую ты ему говоришь?

```python
motor.start()

# Скажи мотору работать на 60 RPM (1 оборот в секунду)
motor.run(60)

# Измерь ровно 1 секунду
start = motor.get_position()
time.sleep(1)
end = motor.get_position()

# Как далеко он прошёл?
moved = end - start
print(f"Мотор переместился на {moved} импульсов")
print(f"Ожидалось: 3200 импульсов (1 оборот)")
print(f"Разница: {moved - 3200} импульсов")

motor.stop()
```

Близко к 3200? Отлично! Небольшие различия (±100) нормальны.

## Урок 1.5: Движение на точное расстояние

**Цель:** Заставь мотор двигаться ровно на 90 градусов, или ровно на 2 оборота, или на любое точное количество!

### Магия управления позицией

Вместо того чтобы говорить "вращайся со скоростью 30 RPM", ты можешь сказать "переместись ровно на 90 градусов, а потом остановись".

Это супер полезно для:
- Роботизированных рук (переместить сустав ровно на 45 градусов)
- Захватов (открыть ровно на 30 градусов)
- Колёс (повернуться ровно на 2 оборота)

### Установка стартовой точки

Сначала скажи мотору, где "ноль":

```python
motor.start()
motor.zero_position()  # Сейчас это ноль!
```

Это отмечает текущую позицию как твою референсную точку. Все движения будут измеряться отсюда.

### Движение на точные расстояния

**Переместись на 90 градусов вперёд:**
```python
motor.move_by(90, 40, 'degrees')
```

Это означает: "Переместись на 90 градусов со скоростью 40 RPM, затем автоматически остановись."

**Твой код ждёт**, пока движение не закончится! Это как `time.sleep()`, но он знает, когда мотор действительно достиг цели.

### Полный пример

```python
motor.start()

# Установи стартовую позицию как ноль
motor.zero_position()
print("Позиция теперь ноль!")

# Переместись на 90 градусов (четверть оборота)
print("Перемещаюсь на 90 градусов...")
motor.move_by(90, 40, 'degrees')
print(f"Позиция сейчас: {motor.get_position()} импульсов")

# Вернись в ноль
print("Возвращаюсь в ноль...")
motor.move_to(0, 30, 'degrees')
print(f"Позиция сейчас: {motor.get_position()} импульсов")

# Полный оборот
print("Делаю полный оборот...")
motor.move_by(360, 50, 'degrees')
print(f"Позиция сейчас: {motor.get_position()} импульсов")

# Назад в ноль
motor.move_to(0, 40, 'degrees')

motor.stop()
```

**Попробуй:**
```bash
robot lesson 1.5
cd lesson1_5
robot run solution.py
```

### Два способа точного перемещения

**1. `move_by()` - Переместись ОТ того места, где ты есть**

```python
# Начни с позиции 0
motor.zero_position()

# Переместись на 90 градусов вперёд → теперь на 90
motor.move_by(90, 40, 'degrees')

# Переместись ещё на 90 градусов вперёд → теперь на 180
motor.move_by(90, 40, 'degrees')

# Переместись на 90 градусов назад → теперь на 90
motor.move_by(-90, 40, 'degrees')
```

Представь `move_by()` как шаги: "сделай 5 шагов вперёд" перемещает тебя относительно того, где ты сейчас.

**2. `move_to()` - Иди В конкретную позицию**

```python
# Начни с позиции 0
motor.zero_position()

# Иди на 90 градусов → перемещается на 90
motor.move_to(90, 40, 'degrees')

# Иди на 180 градусов → перемещается на 180
motor.move_to(180, 40, 'degrees')

# Иди на 0 градусов → возвращается в 0
motor.move_to(0, 40, 'degrees')
```

Представь `move_to()` как переход в комнату с номером: "иди в комнату 5" отведёт тебя туда, не важно, откуда ты начал.

### Градусы против оборотов

Ты можешь использовать либо градусы, либо обороты:

**Градусы (для углов):**
```python
motor.move_by(90, 40, 'degrees')    # Четверть оборота
motor.move_by(180, 40, 'degrees')   # Половина оборота
motor.move_by(360, 40, 'degrees')   # Полный оборот
```

**Обороты (для нескольких вращений):**
```python
motor.move_by(0.5, 40, 'rotations')  # Половина оборота
motor.move_by(1, 40, 'rotations')    # Один полный оборот
motor.move_by(2.5, 40, 'rotations')  # Два с половиной оборота
```

Используй градусы для маленьких движений, обороты для больших!

### Задача: Квадратная волна

Можешь ли ты заставить мотор двигаться вперёд-назад как квадратная волна?

```python
motor.start()
motor.zero_position()

# Двигайся вперёд-назад 5 раз
for i in range(5):
    motor.move_by(90, 40, 'degrees')   # Вперёд
    motor.move_by(-90, 40, 'degrees')  # Назад

motor.stop()
```

### Задача: Часы

Заставь мотор работать как минутная стрелка часов:

```python
motor.start()
motor.zero_position()

# Начни на 12 часов (0 градусов)
# Переместись на 3 часа (90 градусов)
# Затем 6 часов (180 градусов)
# Затем 9 часов (270 градусов)
# Назад на 12 часов (0 градусов)

motor.move_to(90, 40, 'degrees')   # 3 часа
time.sleep(1)

motor.move_to(180, 40, 'degrees')  # 6 часов
time.sleep(1)

motor.move_to(270, 40, 'degrees')  # 9 часов
time.sleep(1)

motor.move_to(0, 40, 'degrees')    # 12 часов

motor.stop()
```

## Шпаргалка команд мотора

Вот всё, что ты можешь сказать мотору:

### Запуск и остановка

```python
motor = Motor(1)      # Подключись к мотору №1
motor.start()         # Разбуди мотор
motor.stop()          # Останови и очисти (используй в конце)
```

### Управление скоростью (непрерывное вращение)

```python
motor.run(30)         # Вращайся вперёд на 30 RPM
motor.run(-30)        # Вращайся назад на 30 RPM
motor.run(0)          # Останови (но оставайся заблокированным)
motor.hold()          # То же, что run(0) - останови, но оставайся заблокированным
motor.disable()       # Останови и разблокируй вал
```

### Чтение позиции

```python
pos = motor.get_position()     # Получи текущую позицию в импульсах
rotations = pos / 3200         # Конвертируй в обороты
degrees = pos / 8.889          # Конвертируй в градусы
```

### Управление позицией (точные движения)

```python
motor.zero_position()                    # Установи текущую позицию как ноль

motor.move_by(90, 40, 'degrees')         # Переместись на 90 градусов отсюда
motor.move_by(-180, 30, 'degrees')       # Переместись на 180 градусов назад
motor.move_by(2, 50, 'rotations')        # Переместись на 2 полных оборота

motor.move_to(90, 40, 'degrees')         # Иди на 90 градусов (от нуля)
motor.move_to(0, 30, 'degrees')          # Вернись в ноль
motor.move_to(1.5, 50, 'rotations')      # Иди на 1.5 оборота
```

### Понимание чисел

```
3200 импульсов = 1 полный оборот = 360 градусов
1600 импульсов = половина оборота = 180 градусов
800 импульсов = четверть оборота = 90 градусов

60 RPM = 1 оборот в секунду
120 RPM = 2 оборота в секунду
```
