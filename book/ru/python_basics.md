## Комментарии - заметки для себя

Комментарии - это заметки в твоём коде. Python их игнорирует - они нужны только тебе, чтобы помнить, что делает код.

```python
# Это комментарий - Python игнорирует эту строку
print("Привет")  # Можно писать комментарии и после кода
```

**Используй комментарии, чтобы:**
- Объяснить, что делает твой код
- Напомнить себе, зачем ты что-то сделал
- Помочь другим понять твой код

**Пример:**
```python
# Запустить мотор
motor.start()

# Вращать со скоростью 30 об/мин в течение 3 секунд
motor.run(30)
time.sleep(3)

# Остановить и завершить
motor.stop()
```

Переменные - это как коробочки, в которых ты храни информацию.


## Отступы - ОЧЕНЬ ВАЖНО!

Python использует **отступы** (пробелы в начале строк), чтобы группировать код. Это ОЧЕНЬ важно и часто вызывает проблемы у новичков!

### Что такое отступы?

```python
# Без отступа - это обычный код
print("Начало")

# С отступом - это код принадлежит чему-то
    print("Это с отступом")
```

### Когда делать отступы

Ты делаешь отступ для кода, который находится "внутри" чего-то:

```python
# Условие if
if speed > 50:
    print("Слишком быстро!")      # С отступом - принадлежит 'if'
    speed = 50                    # С отступом - принадлежит 'if'

# Цикл
for i in range(3):
    print(i)                      # С отступом - принадлежит 'for'
    motor.run(30)                 # С отступом - принадлежит 'for'

# Функция
def start_motor():
    motor.start()                 # С отступом - принадлежит функции
    motor.run(30)                 # С отступом - принадлежит функции
```

### Сколько делать отступ?

**Используй 4 пробела** (или одну клавишу Tab). Выбери один вариант и придерживайся его!

```python
# Хорошо (4 пробела)
if speed > 50:
    print("Быстро")

# Хорошо (1 tab)
if speed > 50:
	print("Быстро")

# ПЛОХО (смешивание пробелов и табуляции)
if speed > 50:
    print("Строка 1")      # 4 пробела
	print("Строка 2")      # 1 tab
# Python выдаст ошибку!
```

### Частые ошибки с отступами

**Ошибка 1: забыл сделать отступ**
```python
# НЕПРАВИЛЬНО
if speed > 50:
print("Слишком быстро")        # ОШИБКА! Нужен отступ

# ПРАВИЛЬНО
if speed > 50:
    print("Слишком быстро")    # С отступом!
```

**Ошибка 2: лишний отступ**
```python
# НЕПРАВИЛЬНО
print("Начало")
    print("Дальше")        # ОШИБКА! Зачем отступ?

# ПРАВИЛЬНО
print("Начало")
print("Дальше")            # Отступ не нужен
```

**Ошибка 3: непостоянные отступы**
```python
# НЕПРАВИЛЬНО
if speed > 50:
    print("Строка 1")      # 4 пробела
      print("Строка 2")    # 6 пробелов - ОШИБКА!

# ПРАВИЛЬНО
if speed > 50:
    print("Строка 1")      # 4 пробела
    print("Строка 2")      # 4 пробела
```

## Условия if - принятие решений

Условия if позволяют твоей программе принимать решения.

### Базовое if

```python
speed = 60

if speed > 50:
    print("Едем быстро!")
```

Это проверяет: "Скорость больше 50?" Если да, выводим сообщение.

### If-Else

```python
speed = 30

if speed > 50:
    print("Едем быстро!")
else:
    print("Едем медленно")
```

Если скорость больше 50, выводим "Едем быстро!". Иначе выводим "Едем медленно".

### If-Elif-Else

```python
speed = 45

if speed > 60:
    print("Очень быстро!")
elif speed > 30:
    print("Средняя скорость")
else:
    print("Медленно")
```

**Как это работает:**
1. Проверяем speed > 60 → Нет? Пробуем дальше...
2. Проверяем speed > 30 → Да! Выводим "Средняя скорость" и останавливаемся
3. Если ничего не подошло, выполняем else

### Операторы сравнения

```python
speed = 50

# Равно
if speed == 50:
    print("Ровно 50!")

# Не равно
if speed != 30:
    print("Не 30")

# Больше чем
if speed > 40:
    print("Больше 40")

# Меньше чем
if speed < 60:
    print("Меньше 60")

# Больше или равно
if speed >= 50:
    print("50 или больше")

# Меньше или равно
if speed <= 50:
    print("50 или меньше")
```

**Частая ошибка:**
```python
# НЕПРАВИЛЬНО - используется один =
if speed = 50:          # ОШИБКА!

# ПРАВИЛЬНО - используется двойной ==
if speed == 50:         # Проверка на равенство
```

### Комбинирование условий

```python
speed = 40
distance = 100

# AND - оба должны быть истинны
if speed > 30 and distance > 50:
    print("Быстро и далеко!")

# OR - хотя бы одно должно быть истинным
if speed > 60 or distance > 200:
    print("Либо быстро, либо очень далеко!")

# NOT - противоположное
if not speed > 50:
    print("Не едем быстро")
```

### Примеры с роботом

```python
# Проверка, двигался ли мотор
position = motor.get_position()
if position > 3200:
    print("Мотор прошёл больше 1 оборота!")

# Проверка безопасности
if speed > 100:
    print("Внимание: скорость слишком высокая!")
    speed = 100

# Проверка нескольких моторов
if motor1.get_position() > 1000 and motor2.get_position() > 1000:
    print("Оба мотора сдвинулись!")
```

## Циклы - повторение действий

Циклы позволяют тебе повторять код несколько раз.

### Цикл For с Range

Повторить что-то определённое количество раз:

```python
# Вывести числа от 0 до 4
for i in range(5):
    print(i)

# Вывод:
# 0
# 1
# 2
# 3
# 4
```

**Как работает range():**
```python
range(5)        # 0, 1, 2, 3, 4 (5 чисел, начиная с 0)
range(1, 6)     # 1, 2, 3, 4, 5 (начать с 1, остановиться перед 6)
range(0, 10, 2) # 0, 2, 4, 6, 8 (начать с 0, остановиться перед 10, шаг 2)
```

**Примеры:**
```python
# Считать до 10
for i in range(1, 11):
    print(i)

# Считать десятками
for i in range(10, 101, 10):
    print(i)         # Выведет: 10, 20, 30, ... 100

# Обратный отсчёт
for i in range(5, 0, -1):
    print(i)         # Выведет: 5, 4, 3, 2, 1
```

### Цикл For со списками

Проходить по элементам в списке:

```python
motors = [motor1, motor2, motor3]

for motor in motors:
    motor.start()
```

**Больше примеров:**
```python
# Цикл по числам
speeds = [10, 20, 30, 40]
for speed in speeds:
    print(f"Скорость: {speed}")

# Цикл по именам
names = ["Ева", "Валли", "BB-8"]
for name in names:
    print(f"Привет, {name}!")
```

### Цикл While

Повторять, пока условие истинно:

```python
count = 0

while count < 5:
    print(count)
    count = count + 1

# Вывод: 0, 1, 2, 3, 4
```

**Пример с роботом:**
```python
# Продолжать движение, пока не пройдём 10000 импульсов
while motor.get_position() < 10000:
    motor.run(30)
    time.sleep(0.1)
motor.stop()
```

**Предупреждение:** Будь осторожен с циклами while! Если условие никогда не станет False, цикл будет работать вечно!

```python
# ПЛОХО - работает вечно!
while True:
    print("Никогда не остановится!")

# ХОРОШО - есть способ остановиться
count = 0
while count < 10:
    print(count)
    count = count + 1  # В конце концов count станет >= 10
```

### Break и Continue

**Break** - выйти из цикла немедленно:
```python
for i in range(100):
    if i == 5:
        break        # Остановить цикл, когда i равно 5
    print(i)

# Вывод: 0, 1, 2, 3, 4
```

**Continue** - пропустить на следующую итерацию:
```python
for i in range(5):
    if i == 2:
        continue     # Пропустить, когда i равно 2
    print(i)

# Вывод: 0, 1, 3, 4 (пропустили 2)
```

### Примеры с роботом

```python
# Постепенно ускоряться
for speed in range(10, 101, 10):
    motor.run(speed)
    time.sleep(1)

# Запустить все моторы
motors = [motor1, motor2, motor3, motor4]
for motor in motors:
    motor.start()

# Повторить движение 5 раз
for i in range(5):
    motor.run(30)
    time.sleep(2)
    motor.hold()
    time.sleep(1)
```

## Функции - переиспользование кода

Функции - это переиспользуемые куски кода. Вместо того, чтобы писать один и тот же код снова и снова, напиши его один раз в функции!

### Создание функции

```python
def say_hello():
    print("Привет!")
    print("Приятно познакомиться!")

# Использовать функцию
say_hello()
say_hello()

# Вывод:
# Привет!
# Приятно познакомиться!
# Привет!
# Приятно познакомиться!
```

**Части функции:**
```python
def function_name():    # def, имя, (), и :
    # Код с отступом
    print("Внутри функции")
```

### Функции с параметрами

Параметры позволяют передавать информацию в функцию:

```python
def greet(name):
    print(f"Привет, {name}!")

greet("Ева")       # Выведет: Привет, Ева!
greet("Робот")     # Выведет: Привет, Робот!
```

**Несколько параметров:**
```python
def run_motor(speed, duration):
    motor.run(speed)
    time.sleep(duration)
    motor.stop()

# Использовать
run_motor(30, 3)    # Вращать со скоростью 30 об/мин в течение 3 секунд
run_motor(60, 5)    # Вращать со скоростью 60 об/мин в течение 5 секунд
```

### Функции, которые возвращают значения

Функции могут возвращать результат:

```python
def add(a, b):
    result = a + b
    return result

total = add(5, 3)
print(total)        # Выведет: 8
```

**Примеры с роботом:**
```python
def pulses_to_degrees(pulses):
    degrees = pulses / 8.889
    return degrees

position = motor.get_position()
degrees = pulses_to_degrees(position)
print(f"Мотор на {degrees:.1f} градусах")


def is_motor_moving(motor):
    speed = motor.get_speed()
    if speed != 0:
        return True
    else:
        return False

if is_motor_moving(motor1):
    print("Мотор 1 движется!")
```

### Зачем использовать функции?

**1. Избегать повторений:**
```python
# Без функции - много повторений
motor1.start()
motor1.run(30)
time.sleep(2)
motor1.stop()

motor2.start()
motor2.run(30)
time.sleep(2)
motor2.stop()

# С функцией - написать один раз, использовать много раз
def test_motor(motor):
    motor.start()
    motor.run(30)
    time.sleep(2)
    motor.stop()

test_motor(motor1)
test_motor(motor2)
```

**2. Делать код читаемым:**
```python
# Сложно понять
motor.run(30)
time.sleep(2)
motor.run(60)
time.sleep(2)
motor.run(30)
time.sleep(2)
motor.stop()

# Легко понять
def speed_test():
    motor.run(30)    # Начать медленно
    time.sleep(2)
    motor.run(60)    # Ускориться
    time.sleep(2)
    motor.run(30)    # Замедлиться
    time.sleep(2)
    motor.stop()

speed_test()
```

**3. Организовывать сложный код:**
```python
def setup_robot():
    motor1.start()
    motor2.start()
    motor3.start()
    motor4.start()

def drive_forward():
    motor1.run(40)
    motor2.run(40)
    motor3.run(40)
    motor4.run(40)

def stop_robot():
    motor1.stop()
    motor2.stop()
    motor3.stop()
    motor4.stop()

# Главная программа - очень понятно!
setup_robot()
drive_forward()
time.sleep(3)
stop_robot()
```

## Собираем всё вместе

Вот полная программа для робота, использующая всё, что ты выучил:

```python
# Импортировать инструменты
from evabot import Motor
import time

# Функция для тестирования мотора
def test_motor(motor_id, duration):
    print(f"Тестируем мотор {motor_id}...")

    # Создать и запустить мотор
    motor = Motor(motor_id)
    motor.start()

    # Вращать на разных скоростях
    speeds = [20, 40, 60, 40, 20]

    for speed in speeds:
        print(f"  Скорость: {speed} об/мин")
        motor.run(speed)
        time.sleep(duration)

    # Проверить, как далеко проехал
    position = motor.get_position()
    rotations = position / 3200
    print(f"  Прошёл {rotations:.2f} оборотов")

    # Остановить мотор
    motor.stop()
    print(f"Тест мотора {motor_id} завершён!\n")

# Главная программа
print("=== Программа тестирования моторов ===\n")

# Протестировать моторы 1 и 2
test_motor(1, 1)
test_motor(2, 1)

print("Все тесты завершены!")
```

## Частые ошибки новичков

### 1. Забыли двоеточие

```python
# НЕПРАВИЛЬНО
if speed > 50
    print("Быстро")

# ПРАВИЛЬНО
if speed > 50:
    print("Быстро")
```

**Всегда ставь `:` после:**
- `if`, `elif`, `else`
- `for`, `while`
- `def function_name()`

### 2. Использование = вместо ==

```python
# НЕПРАВИЛЬНО - это присваивает 50 переменной speed
if speed = 50:
    print("Пятьдесят")

# ПРАВИЛЬНО - это проверяет, равна ли speed 50
if speed == 50:
    print("Пятьдесят")
```

### 3. Неправильные отступы

```python
# НЕПРАВИЛЬНО
if speed > 50:
print("Быстро")    # Без отступа!

# ПРАВИЛЬНО
if speed > 50:
    print("Быстро")
```

### 4. Опечатки в именах переменных

```python
# НЕПРАВИЛЬНО
speed = 30
print(Speed)     # Заглавная S - Python думает, что это другая переменная!

# ПРАВИЛЬНО
speed = 30
print(speed)     # Одинаковое написание
```

### 5. Забыли скобки

```python
# НЕПРАВИЛЬНО
print "Привет"    # Нет ()

# ПРАВИЛЬНО
print("Привет")
```

### 6. Деление на ноль

```python
# НЕПРАВИЛЬНО - вызовет ошибку!
result = 10 / 0

# ПРАВИЛЬНО - сначала проверить
if divisor != 0:
    result = 10 / divisor
else:
    print("Нельзя делить на ноль!")
```
